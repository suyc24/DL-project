## Recommended Use

- Use strict missed positives as retrieval seeds: find same-problem or same-pattern traces from the unlabeled/rough-unknown pool, then label first bad step.

- Use false-stop queues as hard negatives when training the next detector/calibrator, especially early valid setup steps that look suspicious.

- Do not launch online intervention from this queue alone; it is intended to reduce the current offline recall/calibration bottleneck.
